# Snake Game

A classic Snake Game built in Python using the Turtle graphics library. The player controls a snake that moves across the screen, eats food to grow longer, and avoids hitting walls or itself. The game tracks the score and updates the display in real time.

## Project Description

This project is a simple arcade-style game inspired by the traditional Snake game. It includes:
- Smooth keyboard controls using arrow keys
- Random food spawning
- Snake growth when food is eaten
- Score tracking and game reset on collision
- A clean black game screen with a classic arcade feel

## Technologies Used

- Python 3
- Turtle Graphics (`turtle` module)
- Object-Oriented Programming (OOP)
- `time` module for frame timing
- Keyboard event handling for controls

## How to Run

1. Make sure Python is installed on your system.
2. Open a terminal in the project folder.
3. Run:

```bash
python app.py
```

## Files

- `app.py` - Main game loop and screen setup
- `snake.py` - Snake movement and logic
- `food.py` - Food spawning behavior
- `scoreboard.py` - Score display and reset logic
